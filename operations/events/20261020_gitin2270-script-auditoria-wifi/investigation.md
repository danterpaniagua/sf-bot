## Requirement (user)
A `.ps1` script to audit laptop problems: installed apps and last use, SMART status, running processes with CPU and RAM available, CPU model, browsers and versions, browser logs, hostname, RAM (model, modules, speeds). Added later by the user: everything gathered in the running folder with an HTML report; last Windows warnings and crashes from the Event Viewer; Windows 10 and 11 compatibility; antivirus warnings (and "high", read as high-severity threats and high antivirus CPU, to confirm); last successful Windows Update run; connected WiFi band (2.4 / 5), channel and channel saturation; ping and jitter against the gateway and against Cloudflare; UTF-8 safety.

## Script: `scripts/audit-laptop.ps1` (read-only; ASCII-only source; ~1,000 lines; Windows PowerShell 5.1+; Windows 10 1809+ and 11)
Creates `audit-<HOSTNAME>-<UTC stamp>Z` inside the folder where it runs (or `-OutDir`) with `report.html` (self-contained, light/dark), `report.json`, `run.log`, `csv\*.csv` (25 tables), `wlan-interfaces.txt` and `wlan-networks.txt` (raw `netsh`; the second contains the names of neighbouring networks). Parameters: `-OutDir`, `-SampleSeconds` 5, `-TopProcesses` 15, `-EventDays` 14, `-MaxEventsRead` 3000, `-PingCount` 50, `-PingIntervalMs` 200, `-PingTargets` (default `1.1.1.1`), `-HttpJitterCount` 30, `-CloudflareUrl` (`https://speed.cloudflare.com/__down?bytes=0`), `-SkipInternet`, `-Open`.

| Section | What is read | Main limits |
|---|---|---|
| Equipo / CPU / RAM | hostname, make, model, serial, BIOS, OS family and build; CPU name/cores/clocks; RAM total, free and modules (manufacturer, part number, capacity, speed, configured speed) | module "model" = SMBIOS part number; some laptops report blanks |
| Discos | `Get-PhysicalDisk` + `Get-StorageReliabilityCounter` (health, temperature, wear, power-on hours, error counters), `MSStorageDriver_FailurePredictStatus` | Windows' view of SMART; empty fields on some controllers or without administrator |
| Procesos | two `Get-Process` samples 5 s apart: CPU % and working set, grouped by name; no command lines | 5 s sample, not a history |
| Aplicaciones | uninstall registry keys; last use from Prefetch (administrator) and UserAssist (current user) matched by executable | approximation; Store apps not listed; many "desconocido" |
| Navegadores | versions (Chrome, Edge, Firefox, Brave, Opera); Windows crash/hang events of browser executables; crash-report file metadata (not opened) | no browsing history, cookies, URLs or passwords are read (the meaning of "browser logs" was interpreted this way; to confirm) |
| Visor de eventos | System + Application, critical/error/warning, last 14 days: counts by provider/id, latest events, crash indicators (Kernel-Power 41, 6008, BugCheck 1001, Application Error/Hang, WHEA, Display 4101, disk, NTFS) with message cut to 200 characters | only `%USERPROFILE%` is masked in messages |
| Windows Update | agent's last successful search/install, history, failed installs, KBs, pending reboot, service state | time zone of the agent's dates assumed UTC |
| Antivirus | Security Center products, Defender status, threat detections with severity, Defender events, antivirus process CPU/RAM | `Get-Mp*` may fail with a third-party antivirus |
| Red / WiFi | adapters and driver versions; WLAN connect/disconnect events; SSID, BSSID, band, channel, radio, rates, signal; channel saturation from the last Windows scan (same-channel and, on 2.4 GHz, overlapping networks; least loaded of 1/6/11); default gateway; ping and jitter to the gateway, ICMP to 1.1.1.1, and 30 HTTPS requests to Cloudflare (warm-up excluded) | SSID may be hidden on recent Windows 11 without location permission; ICMP/HTTPS may be blocked; channel width not evaluated |
| Observaciones | simple flags with stated thresholds (free RAM < 15 %, disk health/wear/temperature, CPU >= 25 % in the sample, browser crashes, crash indicators, antivirus state and detections, update age, WiFi 2.4 GHz and saturation, signal < 50 %, gateway loss/latency/jitter, internet jitter) | warnings to look at, not diagnoses |

Design decisions worth keeping: read-only; the report is made even if sections fail (each section and each JSON key is isolated, failures go to `run.log` and to the report's Notas); accents are written as `~o~`-style tokens and converted at run time, because a copy of the file without its UTF-8 marker made PowerShell 5.1 read it as ANSI ("mÃ³dulos"); hashtables are case-insensitive in PowerShell (the accent map uses an ordinal comparer); Windows performance counters are avoided because their names are localized.

## Traffic and privacy
- Network: 50 ICMP packets to the gateway, 50 to 1.1.1.1 and 31 small HTTPS requests to Cloudflare (which sees the office public IP), about 30 s in total; `-SkipInternet` leaves out the last two.
- The report holds hostname, serial number, installed software, process names, the current WiFi name and BSSID, threat resource paths (cut to 200 characters, `%USERPROFILE%` masked). The raw `wlan-networks.txt` holds neighbouring networks' names. No browsing history. Review a report before it leaves Operaciones.
