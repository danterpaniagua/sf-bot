# Operations — Technical Debt

Standing conditions that make the platform fragile or costly, not scheduled work (that goes in `todo.md`). Current state, edited in place: when a row is fixed, record the fact in the doc it belongs to and delete the row. Rows were drawn from the docs as last recorded, not re-measured; the source column says where to re-read.

| Area | Debt | Impact | Fix (effort) | Source |
|---|---|---|---|---|
| Zabbix scripts | UserParameter scripts symlinked from personal home directories instead of `/opt/scripts/` (unverified risk) | A user's home or account change breaks the item; file permissions follow the home | Move the scripts to `/opt/scripts/`; fix the `Include` lines (Low) | `zabbix_scripts_home_dir_risk.md` |
| Alert routing | Stock Windows and Docker triggers carry only `scope:capacity` / `scope:performance` and reach no one (disk on 13 of 14 loyalty hosts; the 16 triggers of `SF-FACT-PY01`); the new CPU/RAM tiers lack `env:PROD`, so no Telegram | Real failures page nobody | Routing tags and the tier standard on every prod host (Medium) | `zabbix_alert_matrix.md`; `../docs/zabbix_observability.md`; GITIN-2250 |
| Healthchecks | The web scenarios have `verify_peer` and `verify_host` off, only 7 of 37 steps check a response text, and a `0` from `get_enddate.sh` is read as a failed read and keeps the High tier open until 30 days | A certificate fault never fails a scenario; a false alert can stay open | Turn verification on per scenario; fix the expiry item (Medium) | `../docs/zabbix_web_scenarios.md`; GITIN-2249 |
| Monitoring stack | Grafana 7.3.7 stack handed over by a third party (manual backup/update; the Atlas data source plugin is unmaintained, GITIN-1748) | No upgrade path, known risks | Upgrade or replace (High) | `grafana.md`; GITIN-1174 |
| Shared identity | One `itservices` IIS App Pool identity (Azure AD DS) shared across the SmartLoyalty web fleet; a lockout hits every host; no `badPwdCount` alert | Rotation needs a coordinated fleet-wide procedure; a lockout is only found after the fact | Per-service identities or gMSA; alert on `badPwdCount` (High) | `itservices_rotacion_password_runbook.md` |
| Certificates | Several hostnames share one win-acme configuration and one scheduled task per VM; `SFCG-MOBI-02` shuts down nightly (renewal runs through `StartWhenAvailable`); the GoDaddy credential is a PAT/classic key | One broken task or an expired key stops several renewals | Per-host configuration; secret rotation record (Medium) | `waf_apps_cert_automation_runbook.md`; `mobileappservice_ssl_renewal_runbook.md` |
