All output must be in English — including inline questions, clarifications, and follow-ups. Spanish is reserved exclusively for content written to `events/` artifact files, or when the user explicitly requests Spanish.

**Why:** User corrected switching to Spanish mid-conversation for a clarification question ("¿Lo registro en..."). The rule applies universally to all conversational text, not just analysis sections.

**How to apply:** Even short questions like "Do you want to record this in _ops-events.md?" must be written in English. Never flip language mid-response based on topic.
